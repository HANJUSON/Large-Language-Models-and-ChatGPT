# 거대언어모델과챗GPT — Final Project

강의자료실은 이번 학기 팀 프로젝트를 **정상 프롬프트와 비정상 프롬프트를 판별하는 챌린지**로 안내했습니다.

## 확인한 안내

- 프로젝트 데이터: [S-Labs/prompt-injection-dataset](https://huggingface.co/datasets/S-Labs/prompt-injection-dataset)
- 이미 내려받은 데이터와 설명: [기존 데이터셋 안내](../Prompt%20Injection%20Dataset/강의자료실_안내.md)
- 데이터 파일: [train.csv](../Prompt%20Injection%20Dataset/data/train.csv), [validation.csv](../Prompt%20Injection%20Dataset/data/validation.csv), [test.csv](../Prompt%20Injection%20Dataset/data/test.csv)
- 수업 운영 공지는 목요일에 보충 강의·오프라인 토론·멘토와 프로젝트 관련 수업을 진행한다고 안내합니다. 챕터별 온라인 토론의 질문·답변 기준은 별도 수업 운영 규정이므로 프로젝트 채점표로 해석하지 않았습니다.
- 이번에 조회한 프로젝트 공지에는 팀 인원, 제출 형식, 세부 채점표, 정확한 제출 마감이 적혀 있지 않습니다.

데이터셋은 기존 폴더를 연결해 중복 저장하지 않았습니다.
