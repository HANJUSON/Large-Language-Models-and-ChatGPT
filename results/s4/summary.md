# 4단계 A~D 비교 결과 (개발용)

`scripts/eval_abcd.py`가 대표 모델 RoBERTa의 A~D 조건(README 5.3)을 `validation_clean`(2,097행)과 검수한 개발용 추가 평가 사례(keep·relabel 650개)에서 비교한 결과다. A·B는 2단계 실행 `s2-roberta-A-s<seed>`, C·D는 증강 학습 실행 `s4-roberta-C-s<seed>`의 선택 체크포인트를 쓴다(seed 42·123·2026). A·C는 임계값 0.5, B·D는 `validation_clean`에서 고른 seed별 임계값(`thresholds.json`)으로 판정하며, 판정 규칙은 모두 float32 인젝션 점수 ≥ 임계값이다. `validation_clean` 값은 학습 때 저장한 선택 step의 점수로, 사례 값은 체크포인트로 다시 예측한 점수로 계산했다. 값은 seed 평균 ± 표본 표준편차(n−1)이고, 하나라도 N/A인 seed가 있으면 seed별 값을 적는다. 차이는 뒤 조건 − 앞 조건이며 괄호는 원문 그룹 단위 짝지은 bootstrap 95% CI(2,000회, seed 314159, 원문 레이블 층화, 정규화 키가 같은 그룹은 합침)다.

**개발 결과다.** validation과 개발용 사례는 임계값 선택과 증강 설계에 쓴 개발 자료이므로, 아래 판정은 README 1.1 규칙을 개발 단계에 적용해 본 것이며 최종 판정이 아니다. 최종 판정은 `test_clean`과 최종 추가 평가 사례로 한다. 전체 값은 `runs.csv`·`metrics.csv`·`models.csv`·`bootstrap.csv`·`predictions.csv`·`summary.json`에 있다.

- `학습 시도`는 `run.json`의 `attempt`이며, 2 이상이면 다시 학습한 실행이다(재실행 기록, README 4.2·5.3). 2 이상인 실행: 없음.
- `FPR 상한`은 B·D의 임계값을 고를 때 FPR 상한(같은 seed A 조건의 `validation_clean` FPR + 1%p, README 5.3)을 만족하는 후보가 있었는지다(`thresholds.json`의 `cap_met`). 미충족이면 FPR이 가장 낮은 후보를 고른 것이다. 미충족인 조건: 없음.
- A와 C 실행은 seed마다 학습 예산(N = 2,073 update, 평가 시점 691 / 1,382 / 2,073)·설정·공통 목록 파일·데이터 revision·사전학습 가중치·정밀도·결정론 설정이 같고, 환경 기록은 `run.json`의 `env` 전체(Python·OS·torch·CUDA·cuDNN·라이브러리 버전·GPU 이름과 드라이버·`requirements.txt` SHA-256 등 모든 항목)가 같다. 하나라도 다르면 이 스크립트가 거부한다. 선택 step은 달라도 된다(IMP-03).
- A와 C 사이에 달라도 되는 기록은 `lists_meta.json` SHA-256, `build_lists.py` SHA-256, 학습 코드 SHA-256이다(C 학습 전에 `build_lists.py`와 `train.py`가 바뀔 수 있어 허용하며, 두 조건의 값을 모두 적는다). 이 가운데 실제로 다른 것: `lists_meta.json` SHA-256, `build_lists.py` SHA-256, 학습 코드 SHA-256. 학습 코드 SHA-256이 A와 다른 파일: 2개(`scripts/build_lists.py`, `scripts/train.py`). A와 C의 값은 `summary.json`의 `records`에 있다.
- C의 학습 데이터는 원본 11,050행 + 증강 1,697행 = 12,747행이다.
- `thresholds.json`은 여기서 쓴 실행과 대조했다: 기록된 실행 파일 SHA-256 18개가 같고, 선택한 임계값에서의 `validation_clean` TP·FP·FN·TN 기록 6건이 여기서 계산한 값과 같다(여섯 실행의 `run.json`·`predictions_validation.csv` SHA-256과 임계값마다의 TP·FP·FN·TN 기록이 없거나 다르면 이 스크립트가 거부한다).
