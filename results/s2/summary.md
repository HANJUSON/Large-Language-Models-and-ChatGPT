# 2단계 결과 요약

`scripts/summarize_s2.py`가 `runs/s2-<모델>-A-s<seed>/`의 9개 실행 기록에서 만든다. validation만 쓴다(`validation_clean` 2,097행, validation 2,101행). 각 실행의 선택 step(`validation_clean` F1 최대 → FPR 낮음 → 이른 step)에서 임계값 0.5로 판정한다. 평균 ± 표준편차는 seed 42·123·2026의 표본 표준편차(n−1)다. 표의 수는 반올림했고 전체 값은 `runs.csv`·`models.csv`·`summary.json`에 있다.

모든 실행의 학습 예산은 N = 2,073 update, 평가 시점은 691 / 1,382 / 2,073이다(TRAIN-04).
